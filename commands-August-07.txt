Q1 — History no longer gets overwritten by restarts
_save_daily_record() now checks before writing: if an existing record for today has trade(s) and the current session has 0 (fresh restart that missed the session), it logs a warning and skips the overwrite. The real data stays intact.

Q3 + cooldown bypass — bot now reads signals while in a trade
Every 5 minutes during a position, Supertrend + ADX are re-evaluated:

If both oppose the position and we're losing (kept < 0%) → exits immediately ("Signal reversal")
If both oppose but we're still profitable → logs a WARNING and keeps monitoring
Signal reversal exits also set sl_hit_direction so the same direction is blocked, same as an SL
30-min trail cooldown is now signal-gated: if the market flips and the new direction gets 6+ votes within the cooldown window, the bot re-enters immediately instead of sitting idle for the full 30 minutes.

Setup after cloning — 3 steps total:

Install Python 3.12 if you don't have it: winget install Python.Python.3.12 (or download from python.org — check "Add to PATH" during install).
From the repo folder, run:

.\setup.ps1
This creates the venv, installs all packages from requirements.txt, and creates your .env file from the template.
Edit .env (opens in Notepad or any editor) and paste in your KITE_API_KEY and KITE_API_SECRET — you get these from https://developers.kite.trade under your app. Leave TRADING_MODE=paper.
Then, each day before trading:


.\venv\Scripts\python.exe refresh_token.py   # log in via the printed URL, paste back the redirect URL
.\venv\Scripts\python.exe main.py            # starts the bot
If PowerShell blocks the script with an execution-policy error, run Set-ExecutionPolicy -Scope Process -ExecutionPolicy Bypass first (only affects that terminal session).
